# Creative Project Instructions

Read `bible/README.md` and the established bible material before writing. The human
partner determines canon and resolves narrative choices. Ask for missing foundational
material; do not fill the empty reference files with invented characters, history,
world rules, themes, or plot arcs merely to satisfy a prerequisite check.

`bible/characters.md` is the cast overview. Each directory under `bible/characters/`
contains one character's detailed profile, identified by its stable directory name.
The placeholder `character_id` must be replaced before performance.

Develop treatments and scene materials under `Script/`, outside the bible. Preserve
established canon and trace each scene's responsibilities to its assigned story beats.
Keep one Markdown manuscript per episode. Store immutable scene preparation in
`Episode_N/scene_materials/<scene_id>/`, with a version-2 handoff naming the bounded
episode destination. Instantiate real episodes outside `season_template`; the blank
scaffold is never performance-ready. Create handoffs only when their real inputs are ready.

During roundtable performance, each character is instructed to access only its own
folder within `bible/characters/` and to use only its own context and eligible
observations. Do not read or search sibling character folders. The director receives
the full briefing. Actor turns remain response-only; this folder instruction does
not grant tool use or file writes and is not filesystem isolation.
